# Edirne Korsan Taksi

Edirne korsan taksi sınır şehrinin iki yönlü trafiğinde çalışır. Kapıkule'den Bulgaristan'a, İpsala'dan Yunanistan'a geçecek yolcu kapıya bırakılır. Uçak için İstanbul Havalimanı'na gidilir: Edirne merkezden 151 kilometre, 1 saat 39 dakika.

Selimiye Camii ve çarşı çevresi yürünerek gezilir, Karaağaç'taki eski gar için araç istenir. Güneyde Keşan 138 kilometreyle havalimanına merkezden daha yakındır. Yazın Enez ve Saros sahiline inenler için dönüş günü ayrıca sefer yapılır.
